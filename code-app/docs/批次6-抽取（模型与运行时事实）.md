## 2. M2 相关行为（审批链涉及）

### `Prescription_Submit` 提交处方送审

- ownerEntity：`AGG-PRESCRIPTION-001`｜behaviorType：COMMAND｜triggerType：USER_ACTION
- preconditions：prescription.prescriptionStatus IN ['草稿', '已驳回']；处方明细至少一味饮片（INV-04）；超量药味已填写超量理由
- postconditions：{"field": "prescription.prescriptionStatus", "setValue": "待审核"}；{"field": "prescription.submitTime", "setValue": "NOW()"}
- appliedRules：RULE-PRESCRIPTION-DOSE-LIMIT-CHECK, RULE-HERB-TOXIC-TOTAL-LIMIT-CHECK
- requiredPermissions：PERM-PRESCRIPTION-SUBMIT

### `Prescription_Cancel` 处方退回与作废

- ownerEntity：`AGG-PRESCRIPTION-001`｜behaviorType：COMMAND｜triggerType：USER_ACTION
- preconditions：prescription.prescriptionStatus IN ['草稿', '待审核', '审核通过', '已调剂']；R-04 判定结果不为 BLOCK（已发药/已作废不可作废）；作废原因已填写
- postconditions：{"field": "prescription.prescriptionStatus", "setValue": "已作废"}；{"field": "prescription.cancelReason", "setValue": "写入作废原因"}
- appliedRules：RULE-PRESCRIPTION-VOID-DISPATCH
- requiredPermissions：PERM-PRESCRIPTION-CANCEL

### `Prescription_Review` 处方审核

- ownerEntity：`AGG-PRESCRIPTION-001`｜behaviorType：COMMAND｜triggerType：USER_ACTION
- preconditions：prescription.prescriptionStatus == '待审核'；驳回时驳回原因已填写；当前用户具备中药师角色（ROLE-03）
- postconditions：{"field": "prescription.prescriptionStatus", "setValue": "审核通过 或 已驳回"}；{"field": "prescription.reviewerId", "setValue": "当前登录用户"}；{"field": "prescription.reviewTime", "setValue": "NOW()"}
- appliedRules：-
- requiredPermissions：PERM-PRESCRIPTION-REVIEW

### `Herb_ReturnStock` 饮片库存回冲

- ownerEntity：`AGG-HERB-001`｜behaviorType：COMMAND｜triggerType：SYSTEM
- preconditions：R-04 判定结果为 VOID_WITH_ROLLBACK；对应调剂出库流水存在
- postconditions：{"field": "herb.stockQuantity", "setValue": "stockQuantity + 原出库数量"}；{"field": "herb.HerbStockFlow", "setValue": "逐味追加业务类型为「作废回冲」的流水（数量为正）"}
- appliedRules：RULE-PRESCRIPTION-VOID-DISPATCH
- requiredPermissions：PERM-AUTO-STOCK-RETURN

### `Dispense_CreatePending` 创建待调剂记录

- ownerEntity：`AGG-DISPENSE-001`｜behaviorType：COMMAND｜triggerType：SYSTEM
- preconditions：prescription.prescriptionStatus == '审核通过'；该处方不存在调剂发药记录（一对一约束）
- postconditions：{"field": "dispenseRecord.dispenseNo", "setValue": "系统生成"}；{"field": "dispenseRecord.recordStatus", "setValue": "待调剂"}
- appliedRules：-
- requiredPermissions：PERM-AUTO-DISPENSE-CREATE

### `Dispense_CancelPending` 取消待调剂记录

- ownerEntity：`AGG-DISPENSE-001`｜behaviorType：COMMAND｜triggerType：SYSTEM
- preconditions：R-04 判定结果为 VOID_ONLY；dispenseRecord.recordStatus == '待调剂'；处方状态已为「已作废」
- postconditions：{"field": "dispenseRecord.recordStatus", "setValue": "已取消"}
- appliedRules：RULE-PRESCRIPTION-VOID-DISPATCH
- requiredPermissions：PERM-AUTO-DISPENSE-CANCEL

**R-04（作废三分派）表达式**：

```
IF recordStatus IS NULL THEN RETURN 'VOID_ONLY'
IF recordStatus == 'PENDING' THEN RETURN 'VOID_ONLY'
IF recordStatus == 'DISPENSED' THEN RETURN 'VOID_WITH_ROLLBACK'
IF recordStatus == 'ISSUED' THEN RETURN 'BLOCK'
RETURN 'VOID_ONLY'
```
